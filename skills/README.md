# INQULA Skills
INQULA Skills provide reusable instructions for working with INQULA through supported AI assistants and INQULA's Model Context Protocol (MCP).
Skills are designed around practical tasks in INQULA, such as:
Risk assessment
Deviation follow-up
Measures and actions
Internal control
ICT security
Compliance follow-up
Documents
Vendors
Clients
## MCP and Skills
The INQULA MCP server provides the tools an AI assistant can use to interact with INQULA.
Skills describe how those tools can be used for specific tasks and workflows.
Access is always subject to the user's existing INQULA permissions.
